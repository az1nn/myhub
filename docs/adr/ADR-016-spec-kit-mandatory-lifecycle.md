# ADR-016 — Spec Kit as mandatory development lifecycle

## Decision

Material feature work follows Spec Kit before implementation.

## Rationale

Requirements, plans and tasks must remain explicit, reviewable and traceable instead of being reconstructed from code after the fact.

## Consequence

Material implementation without an approved task/spec relationship is non-conforming.
