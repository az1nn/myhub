# ADR-019 — Root-scoped Spec Kit project for initial monorepo

## Decision

MyHub starts with one root-scoped Spec Kit constitution/specification space.

## Rationale

V0.x features cross mobile, API, contracts and infrastructure; one lifecycle and task graph is simpler. Split only when independent ownership/lifecycle is demonstrated.
