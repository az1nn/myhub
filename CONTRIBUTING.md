# Contributing

MyHub is governed by Spec Kit and the Engineering Graph.

Before material implementation:

1. identify/create the Spec Kit feature;
2. clarify and plan it;
3. generate/check tasks;
4. synchronize the Engineering Graph;
5. run impact/conflict analysis;
6. implement only READY tasks;
7. add implementation and test evidence;
8. synchronize PR/Git metadata;
9. pass graph validation.

Approved architecture changes require ADR treatment.

Never author canonical project truth directly in Neo4j.
